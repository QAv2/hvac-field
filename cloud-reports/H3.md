## How it fits with the existing modules

The shared no-run causes (`gen.control_power`, `gen.no_call`) stay the umbrella answers. The controls causes keep
the umbrella's signs and add the check that splits them, so the umbrella still leads until a `ctl.*` check is made.
The opening-move scenario "power at the unit, no 24 V" asserts this. Where a check already existed (`vc.contactor`,
`vc.coil_24v`, `vc.hps_trip`, `vc.lps_trip`, `blr.tt`, `blr.spill_switch`, `rf.probe_cal`, `ahu.sensor_check`), the
controls causes use it instead of adding a twin. `ctl.sensor_ohms` reads the other modules' sensor checks through
`follows`, and `ctl.float_sw` reads `vc.drain` the same way, so causes in those modules are not marked down when a
tech enters the new check.

## What I didn't finish, and known gaps

- **"thermostat blank" picks the `gen.call` chip, not the new display chip.** `common.yaml` has the same exact
  phrase on `gen.call: not_calling`, and the search breaks the tie in file order. The diagnosis is still sensible:
  `controls` gets set to digital thermostat, and `ctl.batteries_dead` is in the top 3, level with the settings cause.
  Fixing it means deleting that one phrase from `common.yaml`, a shared file, so I left it alone.
- **"BAS says on but nothing runs":** the search splits on "but". The first half gives the mismatch chip; the
  second half ("nothing runs") gives `gen.dead = yes`, which pulls "no line power" to the top. On an air handler
  there is no `ctl.cmd_vs_fb` (the AHU module has its own BAS checks), so only `gen.dead` is picked. Fixing this
  properly needs a change in `search.js` (H1's area) or new phrases on `ahu.fan_status`.
- **Limit switch:** no separate controls cause. Limits are already covered by `blr.limit_failed_open`,
  `blr.limit_cycling_no_flow`, `hp.aux_limit_open` and the AHU freezestat. A limit that has been jumpered out is
  covered by `ctl.jumper_left`.
- **Stuck contactor on refrigeration** stays `vc.contactor_welded`. The new `ctl.call_stuck_on` covers the other
  half (24 V still on the coil), and `ctl.coil_v_off` separates them. Both directions have a scenario.
- **TM 5-815-3** (Army HVAC control systems, 1991) wasn't found online. The sensor and 24 V content rests on general
  practice plus UFC 3-410-02. See `research/controls.md`.
